## 未完成的外部验证

真实模型服务返回 HTTP 400、错误码 `Arrearage`，表示服务商账户欠费。因此真实模型的计划生成、跨进程继续和补查验收尚未完成，不能据此声称真实模型全链路已通过。

模型账户恢复后，可运行 `npm run verify:graph:real` 继续验收。该脚本使用独立的 `livedoc_langgraph_real_test` 数据库，不写业务文档。
