## 产品约定

研究写作显式通过 Skill 选择。普通任务不变；计划确认规则不变。缺资料时允许明确标注缺口的部分草稿，事实错误、未处理冲突和核验技术异常不能标记通过。研究步骤最多三次搜索、八轮模型调用；总预算保持现有配置。主管与核验共用一次补查，研究质量问题共用一次纠错循环。长文阈值为目标 4000 汉字或四个正文章节，选区编辑不启用章节重写。

### 真实验收阻塞

`evals/results/research-real-v1/report.json` 保留真实请求与原始错误。该任务在最初模型调用处收到 HTTP 400，供应商错误码 `Arrearage`。沿用既有累计计数，由 49 增至 50/100；不重置计数，不继续重复欠费请求。正确性、完整性、证据支持、成本改善和人工复核均未据此判定通过。

真实评测最初因敏感数据外发疑虑被自动审批拒绝；检查脚本后证实其新建独立测试库与向量集合、使用合成 business 用户、检索范围只含本次创建的 Orion 资料 ID，且联网关闭。提交这些证据后，同一评测获准运行；没有发送业务知识库内容。

### 兼容与边界

新增内容只使用现有产物表，不需要新增迁移。普通 v2 保持 `agent-v2-policy-1`，研究写作使用 `agent-v2-research-1`；v1 保持旧拓扑。策略按结构而非 JSON 字段顺序比较，指纹保持既有规则。

研究明细与覆盖报告保存其确切来源产物引用，读取时逐项重新校验；即使原步骤已经失效，也不能绕过撤权或版本检查。研究 SSE 事件加入原进度鉴权出口。

长文核验按段落分批，代码、表格等原子块不拆开，单个超大块仍受模型上下文和输出上限约束。步骤内部未完成的调用可能重做，已完成步骤与章节按指纹复用，累计预算不重置。

操作、接口、模型路由、验收命令及回退见 [research-writing.md](research-writing.md)。
